# GUI — DoRoboty.ai Navy Signal

The required visual direction is **Navy Signal**. Read
[docs/design-system/NAVY_SIGNAL.md](docs/design-system/NAVY_SIGNAL.md) before UI work.

## Apply in this app

- Use navy `#06152D` for the public app bar, hero and workspace navigation.
- Use blue `#2D66F5` for actions, links, focus and active controls.
- Use yellow `#F7BD37` sparingly for active navigation and meaningful quality signals.
- Keep listings, profiles, forms and long reading on `#F4F7FC` with white surfaces.
- Use one sans-serif family. Do not introduce serif headings, pink actions or illustrated people.
- Reuse Base UI components and existing product flows; do not create a parallel component library.
- Keep controls at least 44px high, icon canvases 20×20px and card padding at 24px.
- Verify desktop, 390px mobile, keyboard focus, long content and missing-data states.

The old Poster People kit remains under `docs/design-system/agent-kit` only as historical
evidence and is not an active visual reference.
